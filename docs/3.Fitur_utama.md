## 4. Fitur Utama (Detail per Modul)

### 4.1 Manajemen Data Siswa PKL & Penempatan

- CRUD data siswa (dengan opsi import Excel)
- CRUD data tempat PKL/DU-DI (nama, alamat, kontak, bidang usaha, kuota)
- CRUD data pembimbing lapangan per tempat PKL
- Assign siswa → tempat PKL + guru pembimbing + pembimbing lapangan
- Riwayat penempatan (jika siswa berpindah tempat PKL di tengah periode)

### 4.2 Logbook Digital Harian

- Form isi logbook: tanggal, jam mulai, jam selesai, uraian kegiatan, kendala (opsional)
- Upload dokumentasi kegiatan (multiple file — foto/dokumen)
- Status berjenjang: `Draft → Menunggu Validasi → Disetujui / Revisi / Ditolak`
- Siswa dapat mengedit ulang logbook berstatus "Revisi"
- Riwayat & filter logbook per siswa (per tanggal/status)

### 4.3 Dashboard Pemantauan Progres

- Dashboard Guru Pembimbing: persentase pengisian logbook per siswa bimbingan, grafik progres, indikator siswa "belum aktif mengisi"
- Dashboard Admin/Sekolah: sebaran siswa per tempat PKL, status keseluruhan seluruh siswa PKL

### 4.4 Modul Penilaian Akhir

- Komponen/aspek penilaian dapat dikonfigurasi (misal: disiplin, kerjasama, inisiatif, kualitas kerja, tanggung jawab)
- Input nilai per aspek + kalkulasi nilai akhir
- Kolom feedback/catatan kualitatif dari pembimbing lapangan
- Nilai tampil ke siswa & guru pembimbing setelah difinalisasi (status "final", tidak bisa diedit lagi)

### 4.5 Notifikasi Otomatis

- Cron job harian mengecek siswa aktif PKL yang belum mengisi logbook dalam **X hari** (dikonfigurasi Admin)
- Kirim email reminder ke siswa (opsional: tembusan ke guru pembimbing)
- Log notifikasi tersimpan agar tidak terkirim ganda dalam rentang waktu yang sama

### 4.6 Rekap & Ekspor Laporan

- Laporan Monitoring PKL (per siswa/kelas/tempat PKL/periode) — Excel & PDF
- Laporan Sebaran Siswa PKL (per tempat PKL) — Excel & PDF
- _(Perlu konfirmasi ke sekolah)_ — jenis laporan tambahan lain, misal laporan nilai akhir atau rekap kehadiran
