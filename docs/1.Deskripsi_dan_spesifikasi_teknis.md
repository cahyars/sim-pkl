## 1. Deskripsi Umum Proyek

**Nama Aplikasi:** Sistem Informasi Monitoring PKL (SIM-PKL) SMKN 1 Subang

**Tujuan:** Mendigitalisasi proses pemantauan kegiatan Praktik Kerja Lapangan (PKL) siswa SMK, mulai dari penempatan siswa ke tempat PKL, pengisian logbook aktivitas harian, validasi berjenjang oleh guru pembimbing, penilaian akhir oleh pembimbing lapangan (DU/DI), hingga rekap dan pelaporan untuk kebutuhan arsip sekolah.

**Masalah yang diselesaikan:**

- Proses monitoring PKL manual (logbook kertas/WA/Excel) menyulitkan guru memantau progres siswa secara real-time.
- Tidak ada standar validasi & penilaian yang terdokumentasi rapi.
- Sekolah kesulitan membuat laporan rekap PKL untuk kebutuhan arsip/akreditasi.

## 2. Spesifikasi Teknis (Tech Stack)

| Komponen           | Spesifikasi                                                               |
| ------------------ | ------------------------------------------------------------------------- |
| Bahasa Pemrograman | PHP 8.2                                                                   |
| Framework          | CodeIgniter 4 (CI4)                                                       |
| Database           | MySQL / MariaDB (rekomendasi MySQL 8.x)                                   |
| Arsitektur         | MVC (bawaan CI4)                                                          |
| UI Framework       | Bootstrap 5                                                               |
| Autentikasi        | Session-based auth + RBAC (Role Based Access Control) via CI4 Filter      |
| Mobile Friendly    | Wajib untuk role **Siswa** (mobile-first, responsive Bootstrap grid)      |
| Upload File        | Native CI4 File Upload (validasi tipe & ukuran file dokumentasi kegiatan) |
| Notifikasi         | Email (CI4 Email Service / PHPMailer) dipicu oleh CI4 Command + Cron Job  |
| Export Excel       | PhpSpreadsheet                                                            |
| Export PDF         | Dompdf atau mPDF                                                          |
| Query Builder/ORM  | CI4 Query Builder & Model bawaan                                          |
