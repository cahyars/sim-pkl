## Cakupan pengujian tambahan di luar tabel resmi

Beberapa alur turut diuji karena berdampak langsung ke keamanan/kebenaran data, meski
tidak tercantum eksplisit di tabel blackbox di atas:

- **Proteksi lintas-role secara konsisten** di semua modul (bukan cuma menu tersembunyi,
  tapi query di level controller) — dicoba akses langsung via URL/POST manual di modul
  Validasi Logbook, Penilaian, dan Siswa Bimbingan.
- **CSRF protection** aktif global — request tanpa token ditolak (403).
- **Update profil siswa** (No. HP, alamat, foto, ganti password) — termasuk validasi
  password lama yang salah.
- **Toggle aktif/nonaktif akun** untuk siswa, guru pembimbing, dan pembimbing lapangan.
- **Reset password oleh Admin** untuk ketiga role (siswa, guru pembimbing, pembimbing
  lapangan) — diverifikasi sampai berhasil login memakai password hasil reset.
- **Kelola Tahun Ajaran** — tambah periode baru dan hanya satu periode yang boleh aktif
  dalam satu waktu (otomatis menonaktifkan yang lain).
- **Kelola Aspek Penilaian** — tambah/edit/nonaktifkan/hapus aspek, termasuk pengujian
  guard integritas data: aspek yang sudah dipakai pada penilaian tersimpan tidak bisa
  diubah bobot/namanya maupun dihapus, dan minimal satu aspek harus tetap aktif. Aspek
  baru diverifikasi otomatis muncul pada form penilaian pembimbing lapangan.
- **Grafik progres dashboard guru** — data grafik batang (persentase per siswa) dan
  grafik donat (komposisi status logbook) dicocokkan dengan hasil query database dan
  keduanya 100% sesuai.
- **Filter periode/tahun ajaran pada laporan** — diverifikasi memfilter data dengan benar
  dan keterangan periode ikut tercetak pada berkas Excel maupun PDF.
