## 7. Activity Diagram

### 7.1 Login & Redirect Berdasarkan Role

```mermaid
flowchart TD
    Start([Mulai]) --> Input[Input username & password]
    Input --> Cek{Kredensial valid?}
    Cek -- Tidak --> Gagal[Tampilkan pesan error] --> Input
    Cek -- Ya --> CekRole{Role pengguna?}
    CekRole -- Siswa --> DashSiswa[Dashboard Siswa - mobile]
    CekRole -- Guru Pembimbing --> DashGuru[Dashboard Guru Pembimbing]
    CekRole -- Pembimbing Lapangan --> DashLap[Dashboard Pembimbing Lapangan]
    CekRole -- Admin --> DashAdmin[Dashboard Admin]
    DashSiswa --> End([Selesai])
    DashGuru --> End
    DashLap --> End
    DashAdmin --> End
```

### 7.2 Pengisian Logbook oleh Siswa

```mermaid
flowchart TD
    Start([Mulai]) --> Cek{Siswa punya penempatan aktif?}
    Cek -- Tidak --> Blokir[Tampilkan pesan: belum ditempatkan] --> End1([Selesai])
    Cek -- Ya --> Form[Buka form isi logbook]
    Form --> Isi[Isi tanggal, jam, uraian kegiatan]
    Isi --> Upload[Upload dokumentasi kegiatan]
    Upload --> Pilih{Simpan sebagai?}
    Pilih -- Draft --> Draft[Status: draft] --> End2([Selesai])
    Pilih -- Kirim --> Submit[Status: menunggu_validasi]
    Submit --> Notif[Sistem kirim notifikasi ke guru pembimbing]
    Notif --> End3([Selesai])
```

### 7.3 Validasi Logbook oleh Guru Pembimbing

```mermaid
flowchart TD
    Start([Mulai]) --> List[Buka daftar logbook menunggu validasi]
    List --> Pilih[Pilih & buka detail logbook]
    Pilih --> Review[Review uraian & dokumentasi]
    Review --> Keputusan{Keputusan?}
    Keputusan -- Setujui --> Setuju[Status: disetujui] --> NotifSiswa1[Notifikasi ke siswa]
    Keputusan -- Minta Revisi --> Revisi[Isi catatan revisi] --> StatusRevisi[Status: revisi] --> NotifSiswa2[Notifikasi ke siswa]
    Keputusan -- Tolak --> Tolak[Isi alasan penolakan] --> StatusTolak[Status: ditolak] --> NotifSiswa3[Notifikasi ke siswa]
    NotifSiswa1 --> End([Selesai])
    NotifSiswa2 --> End
    NotifSiswa3 --> End
```

### 7.4 Penilaian Akhir oleh Pembimbing Lapangan

```mermaid
flowchart TD
    Start([Mulai]) --> Login[Login sebagai Pembimbing Lapangan]
    Login --> Pilih[Pilih siswa bimbingan]
    Pilih --> CekStatus{Penilaian sudah final?}
    CekStatus -- Ya --> Blokir[Form terkunci, tampilkan riwayat] --> End1([Selesai])
    CekStatus -- Tidak --> Form[Isi nilai per aspek penilaian]
    Form --> Feedback[Isi feedback kualitatif]
    Feedback --> Simpan{Simpan sebagai?}
    Simpan -- Draft --> SimpanDraft[Status: draft] --> End2([Selesai])
    Simpan -- Final --> Konfirmasi[Konfirmasi finalisasi] --> Final[Status: final]
    Final --> NotifSiswaGuru[Notifikasi ke siswa & guru pembimbing]
    NotifSiswaGuru --> End3([Selesai])
```

### 7.5 Notifikasi Otomatis (Reminder Logbook)

```mermaid
flowchart TD
    Start([Cron job berjalan sesuai jadwal]) --> Ambil[Ambil semua siswa dengan penempatan aktif]
    Ambil --> Loop[Untuk setiap siswa]
    Loop --> CekTanggal{Logbook terakhir lebih dari X hari?}
    CekTanggal -- Tidak --> Next[Lanjut siswa berikutnya]
    CekTanggal -- Ya --> CekLog{Sudah dikirim notifikasi hari ini?}
    CekLog -- Ya --> Next
    CekLog -- Tidak --> Kirim[Kirim email reminder] --> Simpan[Simpan log notifikasi] --> Next
    Next --> Habis{Masih ada siswa?}
    Habis -- Ya --> Loop
    Habis -- Tidak --> End([Selesai])
```

### 7.6 Ekspor Laporan

```mermaid
flowchart TD

    GenExcel --> Download[Unduh file]
```
