## 9. Struktur Folder Proyek (CodeIgniter 4)

```
app/
├── Config/
│   └── Filters.php           # daftarkan RoleFilter di sini
├── Controllers/
│   ├── Auth/
│   │   └── AuthController.php
│   ├── Siswa/
│   │   ├── DashboardController.php
│   │   ├── LogbookController.php
│   │   └── ProfilController.php
│   ├── Guru/
│   │   ├── DashboardController.php
│   │   ├── ValidasiLogbookController.php
│   │   └── LaporanController.php
│   ├── PembimbingLapangan/
│   │   ├── DashboardController.php
│   │   └── PenilaianController.php
│   └── Admin/
│       ├── SiswaController.php
│       ├── TempatPklController.php
│       ├── PenempatanController.php
│       └── LaporanController.php
├── Filters/
│   └── RoleFilter.php           # cek session role sebelum akses route
├── Models/
│   ├── UserModel.php
│   ├── SiswaModel.php
│   ├── TempatPklModel.php
│   ├── PenempatanPklModel.php
│   ├── LogbookModel.php
│   ├── DokumentasiLogbookModel.php
│   ├── PenilaianModel.php
│   ├── AspekPenilaianModel.php
│   └── NotifikasiModel.php
├── Libraries/
│   ├── ExcelExport.php          # wrapper PhpSpreadsheet
│   └── PdfExport.php            # wrapper Dompdf/mPDF
├── Commands/
│   └── SendLogbookReminder.php  # dijalankan via cron: php spark send:reminder
├── Database/
│   ├── Migrations/
│   └── Seeds/
└── Views/
    ├── auth/
    ├── siswa/
    ├── guru/
    ├── pembimbing_lapangan/
    ├── admin/
    └── layouts/
        ├── mobile_layout.php    # untuk halaman siswa
        └── dashboard_layout.php # untuk guru/pembimbing/admin
```
